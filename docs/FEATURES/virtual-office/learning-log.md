# Virtual Office Study Notes

> 목적: 구현 전에 핵심 기술의 개념과 대안을 공부하고, 왜 우리 서비스에 적합한지 설명할 수 있는 기록을 남긴다.

## 학습 노트와 ADR의 차이

| 구분 | 학습 노트 | ADR |
| --- | --- | --- |
| 질문 | 이 기술은 무엇이고 어떤 대안이 있는가? | 팀은 무엇을 선택했는가? |
| 내용 | 개념, 비교, 장단점, 실험·확인할 점 | 결정, 이유, 영향, 대안 |
| 상태 | 조사·학습 중에도 작성 가능 | 팀 합의 뒤에만 작성 |
| 위치 | 이 기능 폴더의 `learning/` | `docs/ADR/` |

현재 문서는 학습 노트다. 아래의 채택 방향은 구현 제안이며, 팀이 합의한 뒤에만 ADR로 옮긴다.

## 학습 노트 작성 기준

각 노트는 아래 질문에 답한다.

1. 이 기술 또는 개념은 무엇인가?
2. 어떤 대안과 비교했는가?
3. 우리 서비스에서 얻는 장점과 감수해야 할 한계는 무엇인가?
4. 지금 단계의 채택 제안은 무엇인가?
5. 구현 전에 또는 구현 중에 무엇을 검증해야 하는가?

## ADR로 옮기는 시점

아래 항목이 팀 합의로 확정되면 `docs/ADR/`에 결정 문서를 만든다.

- 가상 오피스 렌더링 도구로 Phaser를 채택하는 결정
- 실시간 Presence 전송 방식으로 Socket.IO를 채택하는 결정
- 맵 제작 도구로 Tiled를 채택하는 결정
- 회의 기능을 LiveKit으로 분리하는 결정

ADR에는 학습 내용을 복사하지 않는다. 결정한 이유, 포기한 대안, 후속 영향만 짧게 남기고 이 학습 노트를 연결한다.
