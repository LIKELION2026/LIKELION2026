## 목적

이 문서는 한국과 베트남의 글로벌 협업 팀이 같은 프로젝트에 연결되어 있음을 보여주는 Virtual Office의 공간 구성과 디자인 에셋 기준을 정리한다.

사용자가 화면에 들어왔을 때 아래 세 가지를 바로 파악할 수 있어야 한다.

1. 지금 같은 오피스에 누가 접속해 있는가
2. 각 팀원이 협업 가능한 상태인가
3. 회의가 필요한 경우 어디에서 바로 참여할 수 있는가

## 공간 결정

### 하나의 Global Office, 두 개의 Team Zone

한국 팀과 베트남 팀을 완전히 분리된 Office 화면으로 만들지 않는다. 국가별 화면을 분리하면 다른 팀의 상태를 보기 위해 전환해야 하고, 하나의 프로젝트를 함께 진행한다는 메시지가 약해진다.

대신 하나의 Global Office 안에 각 팀의 데스크 묶음을 둔다.

- Korea Team Zone: 한국 팀이 주로 머무는 데스크 구역
- Vietnam Team Zone: 베트남 팀이 주로 머무는 데스크 구역
- Shared Collaboration Zone: 국가와 관계없이 함께 일하거나 이야기하는 공용 공간
- Shared Meeting Room: 화상회의와 실시간 번역 자막으로 이어지는 공용 회의실
- Focus Zone: 집중 작업 상태인 팀원이 머무는 작은 작업 공간

국가 구역은 국기나 과도한 문화적 장식보다, 구역 표지와 제한된 색상 차이로 구분한다. 전체 공간은 하나의 브랜드·프로젝트 공간으로 보여야 한다.

## 메인 오피스 와이어프레임

```text
┌──────────────────────────────────────────────────────────────────────┐
│ GLOBAL OFFICE                                         Office  Meeting │
├──────────────────────────────────────────────────────────────────────┤
│ ┌───────────────┐                                                      │
│ │ Global Team   │   Korea Team Zone          Shared Meeting Room      │
│ │ 현재 접속 인원 │   [Desk] [Desk]            [회의 테이블]            │
│ │ 연결 상태     │   [Desk] [Desk]            [화면 / 번역 자막]        │
│ │ 내 협업 상태  │                                                      │
│ └───────────────┘          Shared Collaboration Zone                  │
│                             [공용 보드] [라운지]                       │
│                                                                      │
│   Vietnam Team Zone                              Focus Zone           │
│   [Desk] [Desk]                                  [집중 작업 부스]       │
│   [Desk] [Desk]                                                      │
│                                             [회의실 진입 안내]         │
└──────────────────────────────────────────────────────────────────────┘
```

### 배치 원칙

- 팀별 데스크는 일렬이 아닌 `2 x 2` 묶음으로 배치한다.
- 회의실은 가장 명확하게 찾을 수 있는 위치에 둔다. 벽·바닥·표지로 일반 데스크 구역과 구분한다.
- 공용 협업 공간은 두 팀 Zone 사이에 둬서 한 프로젝트에서 만나는 지점으로 보이게 한다.
- 집중 작업 공간은 작은 부스 또는 독립된 책상으로 표현한다.
- 동선은 막히지 않아야 한다. 가구 주변에 최소 한 타일 이상의 이동 공간을 둔다.

## 공간 위 UI와 상호작용

맵이 커질수록 사용자가 걸어서만 팀원을 찾게 하면 안 된다. 아래 UI는 캔버스 위에 겹쳐 보이는 웹 UI로 디자인한다.

### 피플 목록

좌측 상단 메뉴에서 열리는 패널이다. ZEP의 피플 목록 흐름을 참고하되, 우리 서비스에서는 업무 맥락과 일정 정보를 함께 보여 준다.

```text
┌────────────────────────────────┐
│ 피플 목록                  [닫기]│
│ [팀원을 검색하세요           🔍] │
│                                │
│ Korea Team                     │
│ • Mina PM       협업 가능       │
│ • Jisoo Design  집중 작업       │
│                                │
│ Vietnam Team                    │
│ • An Dev        재택 · 내일 휴가 │
│ • Linh Dev      회의 중          │
└────────────────────────────────┘
```

- 검색 기준: 이름, 역할, Team Zone
- 목록 항목: 아바타, 이름, 역할 또는 팀, 현재 상태, 가까운 부재 일정
- 넓은 맵에서도 항상 열 수 있는 고정 진입점으로 만든다.

### 팀원 메뉴와 프로필

아바타 또는 피플 목록의 팀원을 선택하면 작은 메뉴를 먼저 열고, 필요한 경우 프로필 패널로 확장한다.

```text
┌──────────────────────────────┐
│ [아바타] An · Vietnam Dev     │
│ 집중 작업 · 오늘 17:00 응답 가능│
├──────────────────────────────┤
│ 오늘의 작업 보기               │
│ 찾아가기                       │
│ 불러오기                       │
│ 메시지 보내기                  │
└──────────────────────────────┘
```

- `찾아가기`: 내 아바타 또는 카메라가 상대 위치로 이동한다.
- `불러오기`: 회의실 또는 내 위치로의 요청을 보낸다. 상대가 수락해야만 이동한다.
- `메시지 보내기`: 1:1 메시지 작성 패널을 연다.
- 호출·메시지·TODO 열람은 서로 다른 액션으로 구분해, 메뉴가 과도하게 복잡해지지 않게 한다.

### 오늘의 작업 TODO

TODO는 감시 화면이 아니라 사용자가 공개한 오늘의 협업 맥락이다. 데스크 클릭 또는 팀원 프로필에서 같은 정보를 보여 준다.

```text
┌────────────────────────────────┐
│ An의 오늘의 작업                │
│                                │
│ 진행 중  API 응답 오류 수정      │
│ 예정     배포 전 회귀 테스트     │
│ 막힘     QA 계정 권한 확인 필요  │
│                                │
│ 마지막 업데이트 14:20            │
└────────────────────────────────┘
```

- 상태: `예정`, `진행 중`, `완료`, `막힘`
- 공개 기본값: 작업 제목, 상태, blocker 여부
- 세부 메모·개인 메모는 작성자가 선택적으로 공개
- 진행률, 화면 캡처, 활동 시간, 점수 같은 감시성 요소는 디자인하지 않는다.

### 공유 캘린더

팀 공용 주간 캘린더는 오피스 상단 메뉴 또는 공용 보드에서 연다.

```text
┌────────────────────────────────────────┐
│ 팀 일정                     8/17 - 8/23 │
│        월      화      수      목      금 │
│ An     재택    재택    휴가    휴가         │
│ Mina           회의                    │
│ Linh                   집중 작업        │
└────────────────────────────────────────┘
```

- 일정 종류: 휴가, 재택, 부재, 회의, 집중 작업
- 개인 사유·세부 위치는 표시하지 않는다.
- 피플 목록과 프로필에는 현재 또는 가까운 부재 일정만 요약해 보여 준다.

## 타일과 에셋 규격

### 기본 규격

| 항목 | 규격 | 전달 형식 |
| --- | --- | --- |
| 기본 타일 | `32 x 32px` | 투명 배경 PNG |
| 맵 기준 | `1280 x 768px` (`40 x 24` 타일) | Tiled 맵 또는 레이어별 PNG |
| 가구 | `32px`의 배수 | 투명 배경 PNG |
| 기본 아바타 | `32 x 48px` | Sprite Sheet PNG |
| 상태 아이콘 | `16 x 16px` 또는 `20 x 20px` | SVG 또는 투명 PNG |
| UI 아이콘 | `20 x 20px` 또는 `24 x 24px` | SVG 우선 |

현재 코드의 `48px` 격자는 임시 검증용이다. 실제 디자인과 Tiled 맵은 `32px` 타일을 기준으로 한다.

### 필요한 타일·가구

- 바닥: 기본 바닥, 구역 구분 바닥, 회의실 바닥
- 벽: 일반 벽, 모서리, 문, 창문
- 데스크: 일반 협업 데스크, 집중 작업 데스크
- 회의실: 회의 테이블, 의자, 모니터 또는 프로젝션 화면
- 공용 공간: 소파, 공용 보드, 작은 테이블
- 보조 오브젝트: 식물, 수납장, 책장, 조명
- 구역 표지: Korea Team, Vietnam Team, Meeting Room, Focus Zone

가구는 벽처럼 길을 막는 요소와 장식 요소를 구분한다. 충돌이 필요한 가구는 외곽 여백 없이 형태가 명확해야 한다.

### 아바타 Sprite Sheet

| 항목 | 기준 |
| --- | --- |
| 방향 순서 | `down`, `left`, `right`, `up` |
| 이동 프레임 | 방향별 4프레임 |
| idle 상태 | 이동 첫 프레임 재사용 가능 |
| 권장 시트 크기 | `128 x 192px` (`32 x 48px` 프레임 16개) |
| 충돌 기준 | 몸 전체가 아니라 발밑 영역 |

아바타 위에는 표시 이름과 현재 상태가 노출된다. 디자인 시 라벨이 가구나 다른 아바타와 겹쳐도 읽을 수 있도록 반투명 배경 또는 대비 있는 라벨 스타일을 제공한다.

## 필수 장면과 상태

### 1. 오피스 기본 화면

- 상단 헤더: 서비스명, Office, Meeting 이동
- 좌측 상단 상태 HUD: 팀명, 접속 인원, 연결 상태, 내 협업 상태
- 중앙 캔버스: 타일맵, 팀원 아바타, 이름·상태 라벨
- 우측 상단: Shared Meeting Room

### 2. 팀원 상태

| 상태 | 사용자 의미 | 시각 처리 |
| --- | --- | --- |
| 협업 가능 | 메시지·회의 응답 가능 | 초록 점 + `협업 가능` |
| 집중 작업 | 즉시 응답이 어려울 수 있음 | 파랑 점 + `집중 작업` |
| 회의 중 | 회의 참여 중 | 보라 점 + `회의 중` |
| 자리 비움 | 잠시 부재 | 회색 점 + `자리 비움` |

색상만으로 상태를 구분하지 않는다. 아이콘 또는 짧은 라벨을 함께 제공한다.

### 3. 회의실 진입 안내

사용자가 회의실 영역에 들어오면 우측 하단에 작은 안내 패널을 표시한다.

```text
┌─────────────────────────────┐
│ 회의실에 들어왔습니다         │
│ 현재 회의에 참여할 수 있습니다 │
│                 [회의 참여]  │
└─────────────────────────────┘
```

- 오피스 전체를 가리지 않는 크기
- 회의실을 벗어나면 사라짐
- 버튼을 누르면 Meeting 화면으로 이동

### 4. Meeting 화면

Realtime Meeting 담당자가 이어 구현할 화면이다. P0 디자인에는 아래 상태가 필요하다.

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Office       회의 이름                         연결 상태    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                  상대방 영상 또는 화면 공유                   │
│                                                              │
│                  내 영상 미리보기                             │
├──────────────────────────────────────────────────────────────┤
│ 원문 자막                                                     │
│ 번역 자막                                                     │
├──────────────────────────────────────────────────────────────┤
│ [마이크] [카메라] [화면 공유] [회의 나가기]                   │
└──────────────────────────────────────────────────────────────┘
```

- 연결 중
- 카메라·마이크 권한 거부
- 연결 실패
- 영상 통화 중
- 원문과 번역 자막 동시 표시

## Figma 산출물 우선순위

1. `1280 x 768px` Global Office 맵과 `32 x 32px` 타일셋
2. 기본 아바타 1종과 이름·상태 라벨·상태 아이콘
3. 피플 목록, 팀원 메뉴, TODO 보기 패널
4. 내 TODO 편집과 팀 공용 주간 캘린더
5. 오피스 상태 HUD와 회의실 진입 안내 패널
6. Meeting 화면의 기본 상태와 원문·번역 자막 영역
7. 빈 오피스, 연결 중, 요청 대기·거절, 연결 실패 상태
8. 아바타·가구 변형과 시차에 따른 조명 연출

## 후속 확장

시차를 표현할 때 두 개의 독립 Office로 화면을 나누지 않는다. 같은 공간 안에서 Team Zone의 조명, 아바타 활성 상태, 공용 보드 업데이트로 근무 시작·종료와 업무 인계를 표현한다.
