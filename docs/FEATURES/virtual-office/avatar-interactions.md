# 아바타 상호작용과 공용 채팅

## 목적

가상 오피스를 단순한 이동 화면으로 남기지 않고, 팀원이 서로의 공개 업무를 확인하고 가볍게 대화를 시작할 수 있는 협업 진입점으로 사용한다.

## 사용자 흐름

```text
상대 아바타 클릭
  -> 팀원 이름 / 현재 협업 상태 / 공개 TODO 확인
  -> 찾아가기 | 불러오기 | 메시지 보내기

메시지 보내기
  -> 공용 채팅 입력창에 @팀원이름 입력
  -> office Socket 방에 메시지 중계
  -> 모든 참여자의 채팅 패널과 발화자 말풍선에 표시
```

## 데이터와 권한

- 채팅은 `office.chat.send` Socket 이벤트로 전송한다.
- Server는 연결된 Socket에서 팀과 발신자를 확인하고, 메시지를 같은 오피스 방에만 중계한다.
- Server는 발신자의 선택 언어와 메시지 내용을 기준으로 원문 언어를 기록하고, 한국어·베트남어 상대 언어 번역문이 있으면 `office.chat.message` payload에 함께 담는다.
- Client는 입장 시 선택한 언어 기준으로 번역문을 우선 표시하고, 번역 메시지에는 원문을 함께 남긴다.
- 메시지는 최대 160자로 제한한다.
- MVP에서는 대화 이력을 DB에 저장하지 않는다. 새로고침하거나 재접속하면 기존 대화는 복구하지 않는다.
- TODO는 기존 공개 TODO 조회 API를 사용한다. 선택한 팀원의 비공개 TODO는 표시하지 않는다.

## 사용자 경험 원칙

- 상태와 TODO는 감시나 생산성 평가를 위한 정보가 아니다.
- 메시지 보내기는 현재 공용 채팅에 `@이름`을 채워 주는 빠른 진입점이다. 1:1 저장 메시지와 알림은 후속 범위다.
- 말풍선은 4초 뒤 자동으로 사라져 화면을 계속 가리지 않는다.
- 아바타 위 이름·상태, 선택 패널, 채팅 패널은 협업 보드와 같은 픽셀 카드 토큰을 사용한다.

## 확인 항목

1. 두 브라우저가 같은 오피스에 입장한다.
2. 한 브라우저에서 상대 아바타를 클릭해 공개 TODO와 액션을 확인한다.
3. `메시지 보내기`를 눌러 입력창에 상대 이름 멘션이 채워지는지 확인한다.
4. 메시지를 전송하면 두 브라우저의 채팅 패널과 발화자 아바타 말풍선에 즉시 표시되는지 확인한다.
5. 연결되지 않은 상태 또는 빈 메시지는 전송되지 않는지 확인한다.
