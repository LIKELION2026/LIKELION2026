# gray-cat 아바타 프리뷰 보류

## 현재 정책

`gray-cat.webp` 원본은 표준 스프라이트 규격과 달라 신규 세션 배정을 보류한다. 새 게스트는 red-panda가 사용하는 `office-avatar`만 받는다.

| 구분 | 현재 신규 게스트 | gray-cat 재도입 조건 |
| --- | --- | --- |
| 저장된 `avatar_id` | `office-avatar` | 표준 시트 제공 뒤 `gray-cat` |
| 스프라이트 | `image.png`의 `1536 x 1024`, `6 x 4`, 프레임 `256px` | 같은 규격의 투명 PNG |
| 정지 | 방향별 idle 프레임 | 방향별 idle 프레임 |
| 이동 | 방향별 6프레임 보행 애니메이션 | 방향별 6프레임 보행 애니메이션 |

`avatar_id`는 세션 응답과 Socket의 `OfficeMemberPresence`에 포함된다. 현재 서버의 `selectNewGuestAvatarId()`는 `office-avatar`만 반환한다.

## 보류 원인

현재 gray-cat 원본은 `1619 x 971`의 비표준 아틀라스다. 표준 시트처럼 프레임 경계, 보행 순서, 프레임별 투명 여백이 일관되지 않아 `image.png`와 동일한 렌더링 품질을 보장할 수 없다.

## 재도입 조건

- PNG, 투명 배경, `1536 x 1024`
- `256 x 256` 프레임 24개, `6열 x 4행`
- 1행: idle `아래, 위, 좌, 우`
- 2행: 아래 보행 6프레임
- 3행: 위 보행 6프레임
- 4행: 좌 또는 우 보행 6프레임, 반대 방향은 수평 반전 가능
- 캐릭터 발 위치와 투명 여백을 모든 프레임에서 통일

표준 시트가 준비되면 `avatar-sprite-definition.ts`의 gray-cat 정의만 교체하고, 상하좌우 정지·보행, 원격 표시, 정지 전환을 다시 검증한다.

## 현재 검증 결과

- 2026-08-17 서버 단위 테스트에서 신규 세션 선택값이 `office-avatar`인 것을 확인했다.
- 기존 `gray-cat.webp`는 에셋 파일로만 남기며 사용자 세션에는 배정하지 않는다.
