# 오피스 맵 충돌 영역

## 해결하는 문제

오피스 맵이 단일 배경 이미지로 표시되면 아바타가 책상, 소파, 회의 테이블, 벽을 통과한다. 화면에서 보이는 공간 경계와 실제 이동 경로가 달라져 다른 팀원의 위치와 오피스 공간이 신뢰되지 않는 문제가 생긴다.

## 구현 범위

- `office-collision.ts`에 맵 좌표 기반의 고정 충돌 영역을 선언한다.
- Phaser Arcade Physics의 static body로 벽과 주요 가구를 막는다.
- 문과 복도 등 이동 경로는 충돌 영역에서 제외한다. 화상회의 트리거 영역은 가구 충돌과 겹칠 수 있다.
- 찾아가기·불러오기처럼 위치를 즉시 바꾸는 동작은 막힌 영역 안에 배치되지 않도록 가장 가까운 이동 가능 위치를 사용한다.
- 초기 생성·복원 위치가 막힌 영역이면 가장 가까운 이동 가능 위치로 보정하고, 보정값을 실시간 상태에 다시 동기화한다.

## 좌표 정책

`office-map.png`의 내보낸 해상도 `4096 x 2804`를 게임 월드 좌표로 그대로 사용한다. 충돌 영역도 같은 좌표계를 사용하므로, 맵 가구 위치가 바뀌면 이 문서와 `OFFICE_COLLISION_AREAS`를 함께 조정한다.

## 검증 기준

1. 아바타가 외곽·실내 벽, 업무 데스크 군, 소파·회의 테이블을 통과하지 않는다.
2. 한국팀 6명·베트남팀 6명, 총 12개의 기본 데스크 배정 좌표와 화상회의 트리거 영역 내부에 이동 가능한 위치가 있다.
3. 위치 이동 요청과 초기 생성·복원 위치가 가구 내부를 가리키면 근처의 이동 가능 위치로 보정한다.
4. 화상회의 트리거 영역은 가구 충돌과 겹칠 수 있지만, 내부에 최소 한 곳 이상의 이동 가능 위치를 유지한다.

## 충돌 영역 조정 도구

`/office?debugCollisions=1`로 접속하면 각 충돌 영역이 반투명 빨간 박스와 ID로 표시된다. 오피스 화면에서는 `O` 키로 표시 여부를 전환할 수 있다.

`/collision-editor`는 일반 오피스 메뉴에 노출하지 않는 개발용 조정 화면이다. 맵 위의 충돌 영역을 선택해 이동하고, 네 모서리 핸들로 크기를 조절할 수 있다. 왼쪽 속성 입력란으로 정확한 좌표를 보정하거나, 영역을 추가·삭제할 수도 있다.

같은 화면에서 파란 화상회의 트리거 영역과 초록 초기 자리 마커도 조정할 수 있다. 화상회의 구역은 여러 개를 추가할 수 있으며, 각 구역은 목록 선택 또는 맵 위 드래그와 모서리 조절로 배치한다. `JSON 복사`는 `OFFICE_DEFAULT_DESKS`, `OFFICE_MEETING_ZONES`, `OFFICE_COLLISION_AREAS` 선언을 함께 생성한다. 각 선언을 안내된 파일에 붙여 넣은 뒤 `/office?debugCollisions=1`에서 아바타 이동 경계와 오버레이를 함께 검토한다. 사용자용 화면과 기본 배포 상태에서는 이 오버레이와 편집기 링크를 표시하지 않는다.

## 제한사항

현재 충돌 영역은 Figma 내보내기 이미지에 맞춘 사각형 근사치다. 가구 단위의 픽셀 정밀 충돌이나 원격 사용자의 비정상 좌표 검증은 후속 범위로 둔다.
