# 오피스 맵 충돌 영역

## 해결하는 문제

오피스 맵이 단일 배경 이미지로 표시되면 아바타가 책상, 소파, 회의 테이블, 벽을 통과한다. 화면에서 보이는 공간 경계와 실제 이동 경로가 달라져 다른 팀원의 위치와 오피스 공간이 신뢰되지 않는 문제가 생긴다.

## 구현 범위

- `office-collision.ts`에 맵 좌표 기반의 고정 충돌 영역을 선언한다.
- Phaser Arcade Physics의 static body로 벽과 주요 가구를 막는다.
- 문, 복도, 회의실 입구는 충돌 영역에서 제외한다.
- 찾아가기·불러오기처럼 위치를 즉시 바꾸는 동작은 막힌 영역 안에 배치되지 않도록 가장 가까운 이동 가능 위치를 사용한다.

## 좌표 정책

`office-map.png`의 내보낸 해상도 `4096 x 2804`를 게임 월드 좌표로 그대로 사용한다. 충돌 영역도 같은 좌표계를 사용하므로, 맵 가구 위치가 바뀌면 이 문서와 `OFFICE_COLLISION_AREAS`를 함께 조정한다.

## 검증 기준

1. 아바타가 외곽·실내 벽, 업무 데스크 군, 소파·회의 테이블을 통과하지 않는다.
2. 기본 데스크 배정 좌표와 회의실 입구는 이동 가능 영역에 있다.
3. 위치 이동 요청이 가구 내부를 가리키면 근처의 이동 가능 위치로 보정한다.

## 제한사항

현재 충돌 영역은 Figma 내보내기 이미지에 맞춘 사각형 근사치다. 가구 단위의 픽셀 정밀 충돌이나 원격 사용자의 비정상 좌표 검증은 후속 범위로 둔다.
